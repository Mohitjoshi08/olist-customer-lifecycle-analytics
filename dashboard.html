Model Interpretation & Business Value
Rather than relying solely on descriptive, historical customer spend, we implemented predictive models to proactively target accounts:
  • Customer Lifetime Value (CLV) Prediction: Standard RandomForestRegressor models the customer value from initial transaction attributes. The strongest predictor is first_order_value (98.1%), validating that acquisition-stage spending is the most significant anchor of lifetime value.
  • Repeat Purchase Propensity / Churn Classifier: Models the probability of a customer ordering again based on initial experience. The primary drivers are first_avg_freight (14.0%) and first_delivery_days (11.4%), proving that high shipping fees and slow logistics are the principal inhibitors of customer retention.
Proposed Data Analytics Platform Architecture
To transition this portfolio project into an end-to-end analytics platform, we designed an automated, structured data pipeline using **Apache Airflow** and **dbt (data build tool)**:

Olist OLTP

PostgreSQL transactional database (Raw sources)

➔

Airflow Pipeline

Automated daily extraction of transaction files

➔

BigQuery RAW

Cloud landing zone for unstructured raw views

➔

dbt Modeling

SQL tests, deduplication & dimension building

➔

Analytics Layer

Optimized Star Schema (FactSales & Dimensions)

  • Extract (Apache Airflow): Daily cron scheduling triggers ingestion tasks to pull order and review streams, loading them as raw partitions into the cloud storage and landing schema.
  • Transform (dbt): Modular SQL models map staging tables, execute automated data quality tests, and compile flat dimensional tables to feed the Star Schema models.
  • Load & BI: Transformed layers are loaded into the analytics schema to enable fast dashboard rendering and python-based machine learning training scripts.
